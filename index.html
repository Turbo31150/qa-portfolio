CI GitHub Actions

Installe Playwright + dépendances, lance les tests API et E2E à chaque push.

Reproduire en local : python3 -m venv .venv && source .venv/bin/activate → pip install playwright pytest requests → playwright install chromium → pytest -v. Cibles de démo publiques : saucedemo.com & jsonplaceholder.typicode.com.

Éthique & méthode

Bugs réellement reproduits et vérifiés manuellement. Sur les plateformes de crowdtesting : je teste et documente moi-même ; l'outillage aide à la rédaction et à l'automatisation, jamais à simuler une participation. Recherche de sécurité / bug bounty : uniquement sur périmètre autorisé (in-scope). Respect strict des CGU et de la confidentialité (NDA) : aucun nom de client ou d'application testée n'est publié ici.
